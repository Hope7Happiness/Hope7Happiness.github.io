Purpose and Google data

This OAuth registration is intended only for its owner's private desktop calendar tools. An authorized tool can access the Google Calendar information covered by the permissions the owner explicitly approves. The intended initial use is viewing the owner's calendars and events.

Local tools and storage

The owner chooses and runs the software that uses this client. Client credentials, authorization tokens, and any downloaded calendar data must be protected on the owner's device. This registration does not provide a hosted backend or establish a retention schedule for a separate tool. Review that tool's data handling before granting access.

Sharing and use

The intended use is personal calendar assistance. This registration does not authorize selling Google user data, advertising use, or sharing calendar data with unrelated parties. Any separate service selected by the owner has its own data practices; using this client does not remove the need to review and authorize those practices.

Control and deletion

The owner can revoke access at Google Account connections, and remove locally stored credentials, tokens, and downloaded data from the software that holds them. Revocation prevents future authorized access; it does not erase copies already stored by a separate tool.

This information website

These static pages do not collect calendar events, Google tokens, or OAuth credentials. They contain no application analytics or tracking scripts. GitHub Pages hosts the website and may process ordinary web request information under its own privacy policies.
