My Personal Calendar

A private desktop OAuth registration maintained by Hanhong Zhao for accessing his own Google Calendar with locally configured calendar software. This is not a public calendar service.

Google asks the account owner to approve the permissions requested by the local software. Creating this OAuth client does not itself grant access to calendar data. Access can be revoked from the owner's Google Account at any time.

This static website provides application information only. It does not receive Google authorization callbacks, credentials, tokens, or calendar events.
